# Laboratório Interativo de Algoritmos de Ordenação

## Sobre o projeto

O Laboratório Interativo de Algoritmos de Ordenação é um projeto educacional desenvolvido para demonstrar como os algoritmos Bubble Sort e Selection Sort organizam números.

## Objetivos

- Compreender o funcionamento dos algoritmos de ordenação.
- Comparar diferentes métodos de ordenação.
- Praticar programação com HTML, CSS e JavaScript.

## Algoritmos disponíveis

### Bubble Sort
Compara elementos vizinhos e troca suas posições quando estão fora da ordem desejada. Repete esse processo até que os números estejam ordenados.

### Selection Sort
Procura o menor ou o maior elemento da parte ainda não ordenada e o coloca na posição correta.

## Como utilizar

1. Digite os números separados por vírgulas.
2. Escolha a ordem crescente ou decrescente.
3. Selecione Bubble Sort ou Selection Sort.
4. Clique em "Ordenar números" para visualizar o resultado.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Testes realizados

Foram testados números repetidos, números negativos, ordem decrescente, campo vazio, texto inválido, apenas um número e vírgula dupla.
